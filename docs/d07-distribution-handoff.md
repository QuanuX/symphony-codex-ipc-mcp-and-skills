   profiles. Retain public publisher metadata and legal attribution. Optional
   personal contact fields are omitted; the public QuanuX contact route remains.
2. Build the existing C++26 bridge with explicit compilers in a fresh private
   environment. Inspect final loader/signature metadata and source-path privacy.
3. Run the focused catalog, bridge, adapter and packet-verifier regressions and
   deterministic package checks. Preserve every packaged source member's digest.
4. Bind the final client commit and exact qxctl, bridge, catalog and package bytes.
   Run the existing actual Codex app-server harness in new private profiles for
   stdio and same-user IPC. Retain assertion ledgers, configuration hashes and
   transcript hashes outside distributable source.
5. Run the separate distribution compatibility gate against independently reviewed
   requirements. Missing actual-client evidence remains incomplete. Keep the
   legacy W13 self-stamp limitation explicit.

Actual Codex qualification uses disposable SOV configuration and never invokes
synthetic targets or trading jobs. It does not change installed client profiles,
start an application service, configure credentials, probe providers, publish a
package or run a model turn. Deterministic client calls do not establish GUI
